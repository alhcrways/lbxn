# 蜡笔小新桌宠 v1.0.4

Windows 10/11 64 位。

- `Shinchan-Pet-1.0.4-Setup.exe`：安装版，可选择安装目录。
- `Shinchan-Pet-1.0.4-Portable.exe`：免安装版，下载后直接运行。

## 更新内容

- 护眼走动提醒：默认每 60 分钟提醒，可在右键面板的开关旁输入 1～1440 分钟，按 Enter 或离开输入框自动保存。
- 到时小新会沿当前高度在屏幕左右边缘反复折返，显示简洁长条休息提示；双击小新结束本次提醒、恢复眨眼形象，并开始下个提醒周期。
- 统一左右走动与默认形象的配色；修正走动高度漂移，提高移动速度。
- 桌宠支持 50%～200% 缩放，重启后记住大小。
- 透明区域自动鼠标穿透，可以操作后面的软件；只有人物可拖动，聊天图标按实际鼠标位置显示。
- 右键面板保持打开，支持连续调整，提供关闭按钮及 Escape 关闭。
- 便利贴支持左右调宽、底部调高并保存尺寸；固定后默认隐藏 ＋/×，点击时显示，失焦后隐藏。
- 包含当前好友消息客户端；使用好友通信需要双方连接同一个自行部署的通信服务，见仓库 docs/SOCIAL.md。

请先退出旧版桌宠再启动新版。原有便签和本地设置保留；护眼提醒在重新启动后重新计时。
