# 蜡笔小新桌宠 v1.0.5

修复 Windows 正式版打开右键控制面板时可能出现的 “A JavaScript error occurred in the main process / EPIPE: broken pipe, write” 异常弹窗。

- 删除正式版中遗留的渲染日志转发和浮层调试输出，避免对已关闭的启动器控制台写日志。
- 为标准输出、标准错误添加仅针对 EPIPE 的保护；其他异常仍正常报告。
- 加入真实打包产物回归测试：关闭启动器 stdout/stderr 后，连续打开右键面板、缩放、保存提醒间隔和手动关闭。
- 护眼提醒、行走动画、便签及现有本地数据不变。

Windows 10/11 64 位：

- `Shinchan-Pet-1.0.5-Setup.exe`：安装版。
- `Shinchan-Pet-1.0.5-Portable.exe`：免安装版。

请先退出旧版（包括托盘中的旧进程），再启动或安装新版；无需删除原有便签和配置。
