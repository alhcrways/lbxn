# 蜡笔小新桌宠 v1.0.6

修复便携版运行期间再次双击 EXE 后，右键面板出现 CSS 代码、聊天窗口布局异常的问题。

- 每次便携版启动使用独立的临时解压目录。重复启动只唤醒已有的小新，不再删除正在使用的 Chromium 界面资源。
- 聊天窗口打开后，鼠标放到人物身上仍显示聊天图标，点击可以再次唤起已有窗口；移到空白处仍隐藏。
- 增加真正的 Portable EXE 重复启动回归检查，验证运行资源完整性、菜单样式、连续缩放和手动关闭。
- 加强打包菜单检查，同时检查页面头部和样式文本，避免只检查按钮而漏掉显示错误。

Windows 10/11 64 位：

- `Shinchan-Pet-1.0.6-Setup.exe`：安装版。
- `Shinchan-Pet-1.0.6-Portable.exe`：免安装版。

请先从系统托盘退出旧版，再安装或启动新版。无需删除原有便签、好友身份和配置；已部署的好友服务器无需重装。
