# 蜡笔小新桌宠 v1.0.7

继续修复便携版运行一段时间后，右键控制面板可能显示 CSS 代码的问题。

- 已用 GitHub 发布的 1.0.6 成品复现：Windows 或清理软件移除便携版临时目录里的 Chromium `.pak` 文件后，新开的面板会失去浏览器基础样式，把 CSS 当作正文显示。
- 在程序包内保存对应运行资源；主进程每 10 秒检查一次，并在打开控制面板、聊天或设置窗口前自动恢复缺失文件。
- 所有独立面板增加防御性样式，即使系统资源异常，也不会把 `<style>`、`<script>` 或页面标题显示给用户。
- 新增真实 Portable EXE 回归测试：运行时移走三个资源文件，再打开面板，验证文件自动恢复且界面保持正常。

Windows 10/11 64 位：

- `Shinchan-Pet-1.0.7-Setup.exe`：安装版。
- `Shinchan-Pet-1.0.7-Portable.exe`：免安装版。

请先从系统托盘退出旧版，再安装或启动新版。原有便签、好友身份、聊天设置和服务器地址都会保留。
