# 小新行走素材

使用内置 ImageGen 生成，参考原始 `src/renderer/public/character/default/blink.webp`，原文件未替换。

- `walk-sheet-default-palette.png`：当前采用，已按默认 `blink.webp` 统一肤色、红衣、黄短裤、橙黄鞋与近黑头发。
- `walking-preview.png`：左右行走 APNG 动画预览。
- `../../src/renderer/public/character/default/walk-right/`：6 张右行帧。
- `../../src/renderer/public/character/default/walk-left/`：6 张镜像左行帧。
- 每帧 543 × 724；固定比例、水平居中、脚底对齐到 y=690；帧间隔 120ms。
- `node scripts/prepare-walking-frames.cjs` 从精灵表提取运行时素材。
- `node scripts/preview-walking.cjs` 封装 APNG 预览。

走动已用于定时护眼提醒，默认每 60 分钟触发；右键面板支持自定义 1～1440 分钟。提醒时显示休息提示并沿当前高度左右折返；双击结束本次提醒、恢复待机并重新计时。按住人物、拖拽、聊天或打开面板时暂停移动。开关和间隔保存到本机 `pet-walking.json`，重启后重新计时；只有当前服装有左右行走素材时才触发。
